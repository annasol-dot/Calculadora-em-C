## Funções 

O programa roda em um menu que fica rodando até que o usuário escolha sair 

As 20 opções disponíveis são 
1. **Soma**
2. **Subtração**
3. **Multiplicação**
4. **Divisão**
5. **Resto da Divisão**
6. **Potência**
7. **Raiz Quadrada**
8. **Porcentagem**
9. **Média de 2 números**
10. **Média de 3 números**
11. **Duplo**
12. **Triplo**
13. **Quadrado**
14. **Cubo**
15. **Positivo ou Negativo** 
16. **Maior entre dois números**
17. **Menor entre dois números**
18. **Valor Absoluto**
19. **Seno**
20. **Cosseno**
0. **Sair** (Encerra o programa)

-------

## Tecnologias Utilizadas

* **Linguagem C**: Linguagem base do projeto.
* ```stdio.h```: Biblioteca para entrada e saída de dados no terminal.
* ```math.h``` : Biblioteca matemática para funções como `pow`, `sqrt`, `fabs`, `sin`, `cos`

-------

```
Escolha uma operacao:
1  - Soma
...
19 - Seno

0  - Sair
```

- Uso de laços como ```while``` para manter o loop do programa
